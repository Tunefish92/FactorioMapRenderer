    Source

    Start the renderer with --serve and open the page from there to choose the save game here.
    Drop a save .zip here or
    Folder (e.g. a server's saves)

    A folder on the machine the renderer runs on; in Docker, mount it, e.g. the saves folder of a Factorio server at /saves. The newest .zip below it is taken.

    SSH

    Uses this machine's ssh with your keys; passwords are not supported. For a folder, the newest .zip below it is taken.

    Game server (RCON)

    Optional, together with a folder or SSH: the server saves the game first (/server-save), so the map shows it as it is now. It also brings the Server tab.
